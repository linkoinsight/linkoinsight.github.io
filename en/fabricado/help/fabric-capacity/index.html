Getting a Fabric capacity

Fabric needs a capacity. Start with Microsoft's trial, which is free for 60 days and is started in Fabric. When you want to pay, you buy an F2 in Azure, from SEK 1,645 a month.

Fabricado's app isn't online yet, so there is nothing to install from us today. This page is about Microsoft's products. So don't start a trial or buy an F2 for Fabricado's sake yet: the trial's 60 days begin when you start it, and a reservation commits you for a year.

Updated 6 November 2026.

Route one: the trial

  1. Sign in to Fabric

    The person who will install

    Sign in at app.fabric.microsoft.com with an account in your own organisation, not a guest account. You get the free Fabric licence the first time you sign in.

  2. Start the trial

    The same person

    Click the account manager at the top right, then "Start trial". If the button isn't there, a Fabric administrator needs to turn on the setting "Users can try Microsoft Fabric paid features". It is normally on already.

  3. Choose a region and note the size

    The same person

    The default is your organisation's home region. Microsoft decides whether the trial is F4 or F64. Note which: the size decides whether readers need Power BI Pro.

According to Microsoft the trial is meant for evaluation and testing. Copilot, data agents and AI functions can't run on it.

Route two: a paid F2

  1. An Azure subscription

    Whoever pays the bill

    It takes a real card, a phone and an identity check. Virtual cards don't work.

  2. Create the capacity

    The subscription owner, or your partner

    Create an F2 in the Azure portal, under Microsoft Fabric capacities. With a one-year reservation it costs SEK 1,645 a month. Without one you pay about SEK 3.79 an hour, SEK 2,765 if it runs all month. List prices on 1 November 2026, excluding VAT.

  3. Check the overage setting

    The same person

    According to Microsoft's page on overage, it is on by default, and its threshold isn't a hard spending cap. Check the setting on your own capacity.

  4. Give access

    The Fabric administrator

    Give the person who will install the Contributor role on the capacity.

How to tell it's done

The trial's status is under OneLake catalog, Govern, Capacities, Trial. A paid capacity shows in the Azure portal under Microsoft Fabric capacities, where you can also pause and resume it. A paused capacity costs nothing but runs nothing either. Fabric moves its menus now and then, so it may look different for you.

Has it stopped? See known errors. What everything costs is under What does Microsoft Fabric cost?

Sources
